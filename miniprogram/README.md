# PÚSY 微信小程序

这是 PÚSY 中国商城小程序第一阶段工程，使用微信原生小程序技术实现，可直接导入微信开发者工具预览。

## 当前已完成

- 首页品牌轮播、分类入口、精选商品和新品展示
- 商品分类与本地搜索
- 商品详情、数量选择和相关推荐
- 本地购物袋、数量修改、删除与免邮提示
- “我的”页面及微信登录流程占位
- 本地压缩品牌素材，无需依赖境外图片域名即可预览

## 打开方式

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择仓库根目录 `/Volumes/工作/pusy`。
4. 当前 `project.config.json` 使用 `touristappid`，可先使用测试号预览；取得正式小程序 AppID 后替换该值。
5. 编译运行。

## 当前边界

当前版本为开发预览，商品数据位于 `data/products.js`，购物袋保存在微信本地存储中。真实微信登录、会员、PostgreSQL、商品库存、订单、支付与售后均未接入生产环境。

## 接入统一 API

后续统一使用 `https://api.pusy.cn`：

- `POST /auth/wechat/login`：接收 `wx.login()` 的临时凭证并建立会员会话
- `GET /products`、`GET /products/:id`：商品与实时库存
- `POST /orders`：服务端重新计算价格并创建订单
- `POST /payments/wechat`：创建微信支付参数
- `GET /account/orders`：查询会员订单

任何微信支付商户密钥、API V3 密钥、数据库密码和小程序上传私钥都不得写入本仓库或小程序前端。
