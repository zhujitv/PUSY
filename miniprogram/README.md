# PÚSY 微信小程序

这是 PÚSY 中国商城小程序工程，使用微信原生小程序技术实现。当前处于“认证前开发模式”，不需要正式 AppID 即可在微信开发者工具中继续开发和预览。

## 当前已完成

- 首页品牌轮播、分类入口、精选商品和新品展示
- 商品分类与本地搜索
- 商品详情、数量选择和相关推荐
- 本地购物袋、数量修改、删除与免邮提示
- 商品优先读取网站 PostgreSQL/API，失败时自动回退本地预览数据
- 商品价格、库存状态和缺货控制使用统一接口字段
- “我的”页面支持明确隔离的本地预览身份
- 正式微信登录服务端接口、会员令牌和会员概览接口
- 本地收货地址编辑与校验
- 结算页、配送方式、订单金额汇总和商品明细
- 认证前本地预览订单、订单结果页和订单列表
- 正式模式复用网站统一订单 API，由服务器重新校验价格、库存和配送费
- 商品收藏与“我的收藏”页面（认证前保存在当前设备）
- 客服表单与本地预览工单，无需调用邮件客户端
- 订单关联售后申请；正式模式按会员身份校验订单归属
- 会员权益中心：等级进度、积分明细、定向优惠券与商品提醒
- 结算页支持选择已发放到当前会员的可用优惠券，并实时显示优惠金额
- 正式会员默认收货地址与网站账户同步，预览模式继续只保存本地地址
- 订单详情展示商品明细、收货支付信息、物流单号、运输轨迹和售后记录
- 订单列表支持待付款、处理中、物流、售后状态筛选
- 订单详情支持支付倒计时、状态刷新和退款进度；正式会员可安全取消未发货订单
- 消息中心统一展示订单、物流、退款、售后、优惠券、补货与降价通知，支持未读筛选和全部已读
- “我的”页面和底部导航会同步展示消息未读数量
- 商品详情支持补货通知和降价通知；认证前仅保存在当前设备
- 本地压缩品牌素材，无需依赖境外图片域名即可预览
- 视觉系统已与 PUSY.CN 移动版统一：品牌粉、黑白按钮、大标题、大图商品卡、细边框和低圆角

## 打开方式

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择仓库根目录 `/Volumes/工作/pusy`。
4. 当前 `project.config.json` 使用 `touristappid`，并已关闭合法域名校验。
5. 在仓库根目录启动网站 API：`npm run dev`。
6. 小程序默认连接 `http://localhost:3000`；如果本机 API 未启动，会自动使用内置商品，不会白屏。
7. 在微信开发者工具中编译运行。

API 地址和预览开关位于 `miniprogram/config/index.js`。认证前保持 `previewMode: true`，不要把任何微信 AppSecret 写入这个文件。

## 当前边界

当前仍不能提交微信审核或发布，限制来自小程序账号尚未认证，而不是代码阻塞。

- 商品：已完成统一 API 与本地回退双模式。
- 登录：预览模式只建立本地身份，不生成或伪造 OpenID。
- 会员：正式登录接口已能签发服务器会话并读取会员等级、积分和订单摘要。
- 购物袋：仍保存在微信本地，但会遵守接口返回的库存上限。
- 地址：认证前保存在本地；正式模式已与会员默认地址双向同步。
- 订单：预览模式只生成 `PREVIEW-` 本地订单；正式模式调用统一订单接口，并读取订单商品、支付时限、退款与物流轨迹。
- 取消：预览模式只改变本地订单；正式模式未付款时释放库存与优惠券，已付款未发货时发起原路退款。
- 客服：预览模式只生成 `PREVIEW-CS-` 本地工单；正式模式进入网站统一客服收件箱。
- 售后：预览模式只生成 `PREVIEW-RET-` 本地申请；正式模式只允许当前会员为自己的有效订单申请售后。
- 会员增长：预览模式展示隔离的空积分/优惠券状态并支持本地商品提醒；正式模式读取统一会员数据并可在结算时使用定向优惠券。
- 消息中心：预览模式使用当前设备的隔离示例消息；正式模式按会员身份读取消息，已读状态会同步到网站数据库。
- 微信支付：等待小程序认证和微信支付商户参数。当前不会调用 `wx.requestPayment`，也不会产生真实扣款。

## 接入统一 API

当前统一使用网站同源 API；本地为 `http://localhost:3000`，网站部署后可改为 `https://pusy.cn`：

- `GET /api/miniprogram/products`：商品、价格与实时库存
- `POST /api/miniprogram/auth/wechat/login`：认证后接收 `wx.login()` 临时凭证并建立会员会话
- `GET /api/miniprogram/account`：会员等级、积分、地址、优惠券、订单商品、物流与售后数据
- `POST /api/miniprogram/addresses`：保存当前微信会员的默认收货地址
- `POST /api/miniprogram/orders`：当前会员取消自己的未发货订单，并复用统一库存释放与退款流程
- `POST /api/miniprogram/support`：会员客服工单，订单关联按会员身份校验
- `POST /api/miniprogram/returns`：会员售后申请，服务器核验订单归属和状态
- `POST /api/miniprogram/product-alerts`：创建或关闭当前会员的补货、降价提醒
- `GET /api/miniprogram/notifications`：读取当前会员的消息与未读数量
- `POST /api/miniprogram/notifications`：将当前会员的一条或全部消息标为已读
- `POST /api/orders`：已接入正式模式，服务端重新计算价格、锁定库存并创建订单
- `POST /api/payments`：下一阶段扩展为小程序 `prepay_id` 与支付参数

## 认证完成后的切换步骤

1. 把正式 AppID 写入根目录 `project.config.json`。
2. 在 Vercel 服务器环境变量配置 `WECHAT_MINIPROGRAM_APP_ID`、`WECHAT_MINIPROGRAM_APP_SECRET`。
3. 将 `miniprogram/config/index.js` 的 `apiBaseUrl` 改为 `https://pusy.cn`，`previewMode` 改为 `false`。
4. 在微信公众平台配置 `https://pusy.cn` 为 request 合法域名。
5. 重新测试登录、会员绑定、订单和支付回调后再提交审核。

任何微信支付商户密钥、API V3 密钥、数据库密码和小程序上传私钥都不得写入本仓库或小程序前端。
